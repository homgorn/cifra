# 001. Раздел Вебмастера — plan (как сделано)

## Подход

Чанки скриптами: данные → страницы A/B/C/D → меню/футер → графики → чистка тона → валидация.

## Чанки и артефакты

| Чанк | Скрипт / действие | Результат |
|---|---|---|
| 1. Данные | `scripts/export/build_wm_data.py` (19 CSV → `js/wm-data.js`) | `WM` JSON: статусы, разделы, бины, топы, деньги+CTR, тренды, пробелы, ссылки, кластеры, ICE, прогноз |
| 2–5. Страницы | 10× `pages/wm-*.html` + глоссарий в `methodology.html` | Стр. 13–22, шаблон шапка/сайдбар/футер как у legacy |
| 6. Навигация | `scripts/export/fix_report_nav.py` | Dropdown «Вебмастер» везде, футеры 4-колоночные, нумерация 1–22, пейджеры связаны |
| 7. Графики | Дописка в `js/main.js` (блок WM, `mk('wm*')`, guard) + таблицы из `WM` | 19 новых графиков, 5 tbody рендерятся скриптом |
| 8. Тон | `scripts/export/fix_tone.py` (36 замен с проверкой ×1) + ручной аудит (субагент) | Нейтральный тон, Яндекс-only, цифры 17 конкурентов / 134 ссылки |
| 9. Валидация | `validate_report.py` (9 групп) + `smoke_wm_js.js` | PASSED / SMOKE OK (36 графиков, 36 canvas, 5 tbody) |

## Риски (закрыты)

- Ручные цифры в графиках → решено сборкой из CSV.
- Расхождение семантики файлов → решено кросс-чеком, зафиксировано в методике.
- Дрейф меню/футеров → решено скриптом `fix_report_nav.py` (идемпотентен).
