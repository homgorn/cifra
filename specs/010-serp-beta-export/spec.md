# 010. Годовые показы, клики и позиции по запросам — spec

Статус: **done** (2026-09-27).

## Цель

Анализ сниппетов и позиций по конкретным запросам был невозможен: эндпоинты
`search-queries/*` на этом аккаунте отдают тексты запросов, а поле `indicators`
всегда пустое. Найден рабочий путь через beta-инструмент.

## Скоуп

- `scripts/export/yw_serp_export.py` с тремя режимами: `limits`, `init`, `status`.
- Выгрузка: `POST /pro/serp/queries/download/` с датами и путями,
  затем `GET /pro/serp/queries/download/{task_id}` и скачивание файла.
- Квоты: 100 URL-дней в сутки, суммарно не больше 100 элементов в датах и
  путях, глубина истории 550 дней, файл живёт 24 часа, считается 20 минут — 2 часа.
- Пути берутся из структуры сайта в панели, отсортированной по числу страниц
  в поиске: главная, каталог, сувенирка, полиграфия, новости, услуги.
- `build_dashboard_data.py` сворачивает выгрузку в запросы: показы, клики,
  CTR, средняя позиция, URL. Мусор с latin-символами (следы неверной кодировки
  на стороне Яндекса) выбрасывается.
- Страница «Видимость» в отчёте показывает таблицу запросов с показами.

## Вне скоупа

- Годовое окно целиком: за один проход доступно 100 URL-дней, поэтому данные
  накапливаются еженедельными прогонами `refresh_all.bat`.
- Полная статистика по страницам за 12 месяцев: эндпоинта для неё в API нет.

## Критерии приёмки

- [x] `limits` показывает `PRO_SERP` активным, остаток 100
- [x] `init` создаёт задачу, `status` скачивает отчёт
- [x] Разобран gzip, который отдаёт Яндекс вместо zip
- [x] Таблица запросов с показами на странице «Видимость»
- [x] Проверка `validate_report.py` зелёная

## Прочие открытия этой сессии по API Вебмастера

- `sqi-history` отдаёт 2 890 точек с 2018 года: SQI рос с 10 до 220.
- `recrawl/quota`: 930 страниц в сутки можно отправить на переобход вручную.
- `important-urls`: 48 отслеживаемых денежных страниц со статусами.
- `links/external/*` отдаёт 403, нужен scope `EXTERNAL_LINKS` в приложении.
  Диагностика встроена в `yandex_oauth.py test`.
- Эндпоинтов статистики по страницам (`search-urls/popular`) в API нет.
