# 005. API-доступ Яндекс (OAuth + экспорты) — spec

Статус: **in progress** — скрипты готовы, ждёт код авторизации из браузера.

## Цель

Подключить API Метрики и Вебмастера через OAuth приложения заказчика,
дописать скрипты-заглушки до рабочих экспортов.

## Скоуп

- `scripts/export/yandex_oauth.py`: auth-url / exchange / test (готово).
- Секреты только в корневом `.env` (есть `.env.example` без значений).
- `scripts/export/metrica_api_export.py`: источники, запросы, входы, цели, e-commerce (готово, ждёт токен).
- `scripts/export/yw_api_export.py`: summary, запросы (popular+history), индексация, события, sitemap, диагностика; host автоопределяется (готово, ждёт токен).
- Старые неверные эндпоинты (`search-queries` голый, `iks/history`, `turbo-pages/stats`) удалены.

## Вне скоупа

- Logs API Метрики (квоты) — после проверки доступности на тарифе.
- Topvisor — уже работает через свой ключ.

## Критерии приёмки

- [x] Скрипты без токена выходят с кодом 2 и понятным сообщением
- [ ] `yandex_oauth.py test`: Метрика OK + Вебмастер OK
- [ ] Оба экспорта отработали с 0 ошибок, JSON лежат в `data/exports/`
