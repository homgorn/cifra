# 003. Офлайн-вендоринг Chart.js — spec

Статус: **done** (2026-09-24).

## Цель

Сайт работает без интернета: графики рисуются из локальной копии Chart.js,
CDN остаётся как fallback.

## Скоуп

- `js/vendor/chart.umd.min.js` (Chart.js 4.4.1, 200 КБ, проверен по сигнатуре).
- `vendor_charts.py`: замена CDN-тега на локальный + fallback через
  `document.write` (сохраняет синхронный порядок для `main.js`), идемпотентен.
- Vendor включён в сборку воркера (файл + роут).

## Вне скоупа

- Вендоринг Google Fonts (остаётся CDN; без сети — системный шрифт, приемлемо).
