# 007. Дашборды DataLens — spec

Статус: **planned** — спека готова, сборка после выбора.

## Цель

Живые цифры для решений: себе — операционный дашборд с автообновлением,
клиенту — публичная ссылка на витрину без доступа к кабинетам.

## Почему DataLens

- Нативный BI Яндекса, бесплатный — вписывается в Яндекс-only.
- Коннектор к Метрике из коробки; Вебмастер/Топвизор/CRM — загрузкой CSV
  из `data/exports/*/`, `topvisor/db/`, CRM-выгрузок.
- Публичный доступ к дашборду по ссылке — шаринг клиенту без хостинга сайта.

## Скоуп (4 вкладки «Себе»)

1. **Трафик** — источники, динамика, отказы/глубина (Метрика-коннектор).
2. **Видимость** — позиции Топвизора, searchable/excluded API Вебмастера, sitemap.
3. **Деньги** — заказы/выручка e-commerce, автоцели (звонки, формы), позже CRM.
4. **Здоровье** — 5xx/4xx истории обхода, дубли диагностики, битые из скриптов.

Клиенту: копия вкладок 1–3 в режиме публичной ссылки + ежемесячный one-pager.

## Формулы и метрики

- CTR = клики / показы (Вебмастер popular/history).
- Доля поиска = визиты_поиск / визиты_все (Метрика).
- ROI = выручка_ecommerce / затраты (затраты — вручную из CRM/актов).
- WoW/MoM — сравнение периодов средствами DataLens.

## Регламент

- Еженедельно: батник перепрогона экспортов → обновление CSV-датасетов.
- Ежемесячно: one-pager клиенту (страница сайта + PDF).
- Алерты (вручную раз в неделю до автоматизации): падение searchable,
  всплеск 5xx, просадка money-запросов.

## Вне скоупа

- Looker Studio и Google-стек. Ручной Excel вместо пайплайнов.

## Критерии приёмки

- [ ] 4 вкладки показывают данные из указанных источников
- [ ] Публичная ссылка открывается без логина
- [ ] Регламент обновления записан и выполняется 2 недели подряд
