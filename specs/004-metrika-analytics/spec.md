# 004. Аналитика Метрики — spec

Статус: **done** (2026-09-25).

## Цель

Разобрать выгрузки Яндекс.Метрики (`metrika/`, период 2023-01-12 — 2026-09-23)
тем же конвейером, что Вебмастер: парсинг скриптом → вики → экспорты → кросс.

## Скоуп

- `build_metrika_data.py`: источники, посещаемость (день/месяц), запросы,
  страницы входа (по хостам), кросс с Вебмастером, `metrika_summary.json`.
- Вики `brain/wiki/metrika_analytics/`: INDEX + 01–05.
- 8 CSV + summary.json в `metrika_analytics/exports/`.
- Короткий раздел в CLIENT_REPORT со ссылкой на вики.

## Вне скоупа

- Страницы Метрики на сайте отчёта (отдельная спека, по запросу).
- Срез «источники × месяц» (нужна доп. выгрузка из Метрики).

## Критерии приёмки

- [x] Конвейер идемпотентен, второй файл входа распознан как дубль и пропущен
- [x] Цифры вики = цифры экспортов (один источник — скрипт)
- [x] Кросс: 62 совпадения с Вебмастером, мусор и чужой трафик задокументированы
