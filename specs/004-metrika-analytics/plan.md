# 004. Аналитика Метрики — plan

## Подход

Как в спеке 001: сначала сырые данные, потом агрегаты, потом выводы. Отличия:
кодировки/разделители определены авто-сниффером, дубли файлов — по хешам содержимого.

## Ловушки (закрыты)

| Ловушка | Решение |
|---|---|
| Два файла входа — почти дубли (3 строки округлений) | Хеш-сравнение, использован один, задокументировано |
| Строка с пустым URL на 79 042 визита | Исключена как артефакт, задокументировано |
| «Входы» на хостах yandex.ru/ya.ru | Это входы через сервисы, не страницы сайта; агрегат по хостам |
| Суммы посетителей ≠ итогам | Дедупликация Метрики, задокументировано в 01 |
| Один счётчик на несколько доменов | Найдено и задокументировано (стейджинг, чужой запрос) |
