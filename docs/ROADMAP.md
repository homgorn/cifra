# Roadmap: SEO-портфолио для типографии (фото → классификация → CSV для WP)

## 1) Цель
Собрать устойчивый конвейер для больших каталогов изображений (сейчас ~1200 фото, далее масштабирование), который:
- переименовывает файлы под SEO;
- классифицирует по категории/подкатегории/признакам (тип, цвет, дополнительные атрибуты);
- генерирует описания и SEO-поля;
- экспортирует CSV, пригодный для WP All Import (free) + Rank Math (free/addon);
- хранит промежуточные результаты, чтобы можно было продолжать с любого шага.

---

## 2) Архитектура пайплайна (рекомендуемая)

### Этап A. Инвентаризация
- Скан папок и фото.
- Считывание EXIF (дата съемки, ориентация, устройство, если есть).
- Формирование `manifest.jsonl` (1 строка = 1 фото).

### Этап B. Нормализация имен
- Транслит + slug + счетчик.
- Формат имени: `{subcategory-or-category}-{brand}-{seq}.jpg`.
- Пример: `ruchka-s-logotipom-cifra18-rf-001.jpg`.

### Этап C. Классификация
- Primary class: категория.
- Secondary class: подкатегория.
- Атрибуты: `color_primary`, `material_guess`, `logo_method_guess`, `orientation`.
- Сохранять confidence и модель, которая выдала предсказание.

### Этап D. Генерация контента
- Отдельно хранить:
  - распознанный "сырой" vision-output (лучше EN);
  - финальный RU SEO-текст для карточки/портфолио;
  - HTML-версию для вставки в `post_content`.

### Этап E. Экспорт CSV
- CSV v1 для WP All Import.
- Отдельный CSV (audit) с ошибками и confidence.
- Проверка уникальности slug/post_name.

### Этап F. QA
- Валидация колонок.
- Проверка недостающих URL, дублей, пустых описаний.
- Отчет `qa_report.csv`.

---

## 3) CSV-стратегия под WP All Import

Для гибкости поддерживать **две колонки URL одновременно**:
1. `featured_image_primary_url` — основной URL (обычно ваш сайт/CDN).
2. `featured_image_backup_url` — резерв (Google Drive / Yandex Disk / иной источник).

Плюс хранить:
- `file_path_local` (локальный путь);
- `media_filename` (имя файла);
- `wp_post_name` / `post_name` (slug).

Это позволяет тестировать импорт на разных источниках изображений без перестройки пайплайна.

---

## 4) Источники медиа: что лучше

### Вариант 1: Сначала загрузка в WP Media
Плюсы:
- управляемо в рамках WP;
- проще для кэша и плагинов.

Минусы:
- тяжелее первичный импорт;
- на shared-хостинге могут быть таймауты.

### Вариант 2: Внешние URL при импорте
Плюсы:
- можно тянуть батчами;
- проще масштабироваться.

Минусы:
- важна стабильная публичная ссылка;
- Google Drive/Yandex Disk часто дают непредсказуемые редиректы/ограничения.

### Практический совет
- Для production лучше S3-совместимое хранилище (например, Cloudflare R2 / Backblaze B2 / Wasabi) с прямыми URL.
- Drive/Disk использовать как временный staging/backup, но не как основной CDN.

## 5) Дешевый compute для CV/LLM (качество > скорость)

### Если главная цель — низкая цена и приемлемое качество
1. **Gemini Flash API** — хороший старт для vision+описаний, простая интеграция.
2. **Kaggle Notebooks** — бесплатно, но сессионные ограничения и нестабильность доступности GPU.
3. **Google Colab Free/Pro** — удобно для прототипа, но с лимитами по времени.
4. **Modal** — удобно для сервиса и автоскейла, но уже платная модель биллинга.

### Экономная стратегия
- Шаг классификации делать легкой моделью/эвристикой.
- Генерацию богатых SEO-описаний запускать только для "финальных" фото.
- Кэшировать ответы модели и не перегенерировать при повторных запусках.

---

## 6) Дорожная карта по релизам

### R1 (быстрый MVP)
- Стандартизировать CSV-колонки.
- Gemini-проход по 50–100 фото.
- QA-валидация и исправление шаблонов.

### R2 (рабочий поток)
- Полный прогон 1200+ фото.
- Подкатегории + атрибуты фильтров.
- Дубли URL (primary/backup).

### R3 (масштаб)
- Мультиязычность (RU → EN + др.).
- Кластеризация похожих фото.
- Поддержка видео (кадры + captions + теги).

### R4 (сервис)
- API-сервис с очередями задач.
- Веб-панель статусов.
- SLA/мониторинг/стоимость на 1 объект.

---

## 7) Риски и как снизить
- Непредсказуемые публичные ссылки Drive/Disk → держать backup URL и локальный путь.
- Просадки качества описаний → добавлять few-shot примеры и словарь терминов типографии.
- Рост затрат на API → батчинг, кэш, повторная генерация только при изменениях.
- Ошибки категорий → human-in-the-loop в low-confidence случаях.

---

## 8) Что делаем сразу
1. Зафиксировать единую CSV-схему (см. шаблон в `templates/wp_portfolio_template.csv`).
2. Вести `raw_vision_en` отдельно от `seo_description_ru`.
3. Добавить `taxonomy_*` и `attr_*` колонки для импорта фильтров.
4. Прогнать pilot-батч на 20–30 фото из 2–3 категорий.
