# Topvisor: данные проекта Цифра18

Единая папка по Топвизору. Все в одном проекте, ничего наружу.

## Структура
```
topvisor/
  README.md        ← этот файл
  INDEX.md         ← индекс всех данных и файлов
  endpoints.md     ← каталог всех методов API v2 с ценами
  .env             ← ключи (в gitignore, не коммитить)
  scripts/
    tv.py          ← клиент с защитой от трат + баланс после каждого запуска
    sync.py        ← полный синк в базу и MD
  db/
    topvisor.db    ← SQLite: проекты, ключи, позиции, конкуренты, баланс, лог вызовов
  exports/
    projects.md    ← проекты и регионы
    keywords.md    ← 154 ключа
    positions.md   ← срезы топов и позиции
    competitors.md ← конкуренты проекта
    balance.md     ← история баланса
```

## Правила денег (требование владельца)
1. Перед любым платным действием предупреждаю о точной цене и жду подтверждения.
2. После каждого запуска показываю остаток счета.
3. Чтение (`get/*`) бесплатное. Платные: проверки позиций, аудит, сбор частотности, кластеризация.
4. Каждый вызов логируется в `api_log` с меткой платный/бесплатный.
