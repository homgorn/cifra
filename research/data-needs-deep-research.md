| # | API | Dimensions / методы | Зачем |
|---|---|---|---|
| A1 | Stats API `/stat/v1/data` | `ym:s:dateMonth × ym:s:lastTrafficSource` + visits/bounce/depth | M6 без ручных выгрузок, автоматом |
| A2 | Stats API | `ym:s:searchPhrase × ym:s:searchEngine` + visits/goals | Запросы с конверсиями, когда появятся цели |

| A6 | Logs API `/logrequests` (источник hits/visits) | Построчные: URL, referer, фраза, движок, город, устройство, isRobot, время ответа, goalsID | Разбор отказов до уровня хитов; точная фильтрация ботов и админки; медленные URL |

## 7. Серверные логи (глазами сервера)

Запросить у хостера access_log за 30 дней (формат: IP, время, метод, URL, код, размер, referer, UA, время ответа). Анализ:
- заход бота Яндекса: частота, глубина, коды (корреляция с PARSE_ERROR/500);
- топ 404 и 5xx (сверка с Вебмастером и внутренними ссылками);
- самые медленные URL (корреляция с «тяжёлыми» страницами);
- мусорный трафик (сканеры, подбор админки).

## 9. Анти-список: не грузить

- GA4, Search Console — вне скоупа (только Яндекс).
- Сырые видео Вебвизора целиком — только выборки под CRO-вопросы.
- Полный дамп dataLayer — шум без настроенных целей.
- Периоды старше жизни счётчика и дубли скачиваний (урок файлов входа).
- Полный построчный лог всех хитов без фильтров — объём ради объёма; сначала агрегаты.
