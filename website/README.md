# Cifra Docusaurus Docs

Полная документация проекта на Docusaurus.

## Запуск

```bash
cd website
npm install
npm run start
```

## Сборка

```bash
npm run build
npm run serve
```

## Содержимое

- `/docs/intro` — overview;
- `/docs/roadmap` — план развития;
- `/docs/wp-all-import-schema` — схема CSV;
- `/docs/test-data-upload` — загрузка test data;
- `/docs/csv-validator` — валидация CSV.
