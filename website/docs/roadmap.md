# Roadmap

## Цель
Построить устойчивый конвейер для больших каталогов изображений и безопасного импорта в WordPress.

## Этапы

1. **Инвентаризация**: скан файлов, EXIF, manifest.
2. **Нормализация**: SEO-slug имена.
3. **Классификация**: категории, атрибуты, confidence.
4. **Контент**: raw vision + финальный SEO текст.
5. **CSV экспорт**: primary/backup URL + атрибуты.
6. **QA**: проверка колонок, дублей, пустых полей.

## Релизы

- **R1 (MVP)**: схема CSV + pilot batch.
- **R2**: полный прогон 1200+ фото.
- **R3**: мультиязычность и кластеризация.
- **R4**: API и web-панель статусов.
