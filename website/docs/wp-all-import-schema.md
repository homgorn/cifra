# WP All Import CSV Schema

## Обязательные колонки

- `post_type`
- `post_status`
- `post_title`
- `post_name`
- `post_content`
- `tax_category`
- `tax_post_tag`
- `featured_image_primary_url`
- `file_path_local`

## Изображения

- `featured_image_primary_url` — основной URL.
- `featured_image_backup_url` — резервный URL.
- `media_filename` — имя файла.
