Почему это бьет по позициям

Вес ссылок и поведенческие сигналы распыляются между копиями вместо одной канонической страницы. В выдаче может закрепиться не та версия, например параметрическая без нормального title.

План канонизации

W-02
Канонический адрес на все страницы
Приоритет 1 • правится в шаблоне один раз
Что сделать
Добавить тег link rel=canonical в шапку шаблона на всех страницах, без параметров пагинации, сортировки и меток
Где править
header.php шаблона cifra_new
Проверка
Исходный код любой страницы содержит canonical на чистый адрес
W-03
Директива Clean-param в robots.txt
Приоритет 1 • правится за час
Что сделать
Прописать Clean-param для ID, PAGEN_1, SORT, ORDER и utm_меток, чтобы робот склеивал копии сам
Проверка
Валидатор robots.txt в панели Вебмастера без ошибок
Clean-param: ID, PAGEN_1, SORT, ORDER, utm_source, utm_medium, utm_campaign
W-04
Редиректы со старых адресов
Приоритет 2 • по карте соответствий
Что сделать
Числовые html и detail.php с ID вести 301 редиректом на актуальные ЧПУ карточек, дубли категорий склеить в одну структуру
Проверка
Статус DUPLICATE в панели стремится к нулю, остаются только валидные копии пагинации
