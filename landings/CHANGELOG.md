  каталога из настоящей выкачки, 16 фотографий, `dist/` 100 КБ.
- Написан `landings/validate_landing.py`: 16 гейтов.
- Проверен живым тестом бэкенд: honeypot, валидация, rate limit,

### Проверено

`python landings/validate_landing.py landings/kvartalnyy-kalendar-2027`

15 гейтов из 16 проходят. Счётчик Метрики 50863157 в инициализации и в

Живой тест бэкенда, проведён на копии в отдельной папке, `dist/backend`

| Проверка | Ожидание | Факт |

| healthz | ok | ok |
| honeypot заполнен | 200, лид не создан | 200, каналы не вызваны |
| пустое имя и телефон из 1 цифры | 400 | 400 |

| rate limit формы | 429 после 5 | 400,400,400,400,429,429 |
| квиз после промахов формы | не 429 | 502, лимит раздельный |

### Что осталось незакрытым

**Блокер публикации: нет реквизитов оператора персональных данных.**
Гейт 8 не проходит. В подвале стоит явная пометка, в `privacy.html`
вместо оператора тоже пометка. Форма при этом собирает персональные
данные.

Реквизиты есть в демо-конфиге блюпринта, но письменного подтверждения
заказчика нет. Переносить их без подтверждения нельзя.

### Известные аномалии в данных сайта

- «Календарь карманный»: 512 шт по 14 ₽ и 1000 шт по 50 ₽, цена за
  штуку растёт с тиражем. Похоже на ошибку у клиента. Цены не
  публикуются, вопрос задан.
- Название страницы раздела «Календари» в выкачке одно на все позиции:
  описание товара на сайте не индивидуальное. В конфиге в `specs` стоит
  разбор названия позиции, а не пересказ этого текста.

### Что не использовано и почему

| Значение | Почему нет |
|---|---|
| «18+ лет на рынке» | нет даты основания, сайт не подтверждает |
| «13+ видов продукции» | нет источника, противоречит каталогу |
| SLA «в течение 15 минут» | нет источника |
| Реквизиты ИП из демо-конфига | нет письменного подтверждения |
| Цены «от N ₽» | не подтверждено письменно, `showPrices: false` |

### Как пересобрать

Четыре шага, порядок обязателен:

```powershell
python landings\_scrape\fetch_catalog.py --parse-only
python landings\_scrape\fetch_images.py --section kalendari --out landings\kvartalnyy-kalendar-2027\assets
python landings\_scrape\optimize_images.py --src landings\kvartalnyy-kalendar-2027\assets --dst landings\kvartalnyy-kalendar-2027\assets\web
python landings\_scrape\build_calendar_config.py
cd landings\landing-blueprint-2
node render.js ..\kvartalnyy-kalendar-2027\config.json ..\kvartalnyy-kalendar-2027\dist
python landings\validate_landing.py landings\kvartalnyy-kalendar-2027
```
