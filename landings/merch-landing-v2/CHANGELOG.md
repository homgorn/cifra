# Что изменилось в v2 → v3 (квиз + AIDA)

## Структура (было 6 секций → стало 9, требование «не менее 7–10 блоков»)
1. Hero — Attention
2. USP — Attention/Trust
3. Способы нанесения — Interest
4. Каталог — Interest
5. **Как проходит заказ — новый блок**, Interest→Desire
6. **Квиз-расчёт (4 шага) — переделан из простого конфигуратора**, Desire
7. Цифры доверия — Desire
8. **FAQ — новый блок**, снятие возражений, Desire
9. Форма + мессенджеры — Action

## Квиз (главное изменение)
- Шаг 1: категория → Шаг 2: товар (все позиции из презентации) → Шаг 3: тираж,
  макет (есть/нужна разработка), срок (стандартный/срочно), пожелания по
  цвету и материалу текстом → Шаг 4: контакты и отправка.
- Специально НЕТ выбора конкретных цветов/материалов по каждому товару —
  в презентации указано только «возможные цвета» без конкретного списка,
  поэтому это осталось текстовым полем, а не выдуманным списком опций.

## Бэкенд
- Новый роут `/api/quiz-lead`: расчёт из квиза уходит **на почту** (nodemailer,
  SMTP из env) и, если настроен, дублируется в Bitrix24.
- Старый `/api/lead` (простая форма) теперь тоже пишет в оба канала.
- Оба роута используют `Promise.allSettled` — если один канал упал, второй
  всё равно доставит лид; отвечают `ok:false` только если упали оба.
- Нужно задать в окружении: `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`,
  `MAIL_TO` (по умолчанию izhcifra@yandex.ru), `BITRIX_WEBHOOK_URL`.
