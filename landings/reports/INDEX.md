## Приём заявок

```
landings/php/
  lead.php                обработчик, три канала доставки
  _harness.php            тестовый стенд, 11 проверок
```

Тест: `php landings/php/_harness.php <порт>`. Стенд поднимает встроенный
сервер и бьёт настоящими HTTP-запросами при намеренно недоступных каналах:
проверяется, что при обрыве всех трёх возвращается честный 502, а не `ok`.

Локально проверено 11 из 11 на PHP 8.3. Не проверено: живая инсталляция,
`CIBlockElement`, `mail()`, доступность вебхука.

### Сборка всех лендингов одной командой

```
python landings/build_all.py                        все одиннадцать
python landings/build_all.py upakovka nakleyki      выборочно
python landings/build_all.py --skip-fetch           без скачивания
```

Порядок шагов внутри важен и задан в `build_all.py`: фото должны быть
скачаны и оптимизированы **до** генерации конфига, потому что генератор
смотрит, есть ли локальный файл, и подставляет локальный путь вместо
адреса на сайте. Поменять местами можно, страница соберётся и пройдёт
гейты, а картинки будут битые.

## Сборка с нуля: четыре шага, порядок обязателен

```powershell
python landings\_scrape\fetch_catalog.py --parse-only
python landings\_scrape\fetch_images.py --section kalendari --out landings\kvartalnyy-kalendar-2027\assets
python landings\_scrape\optimize_images.py --src landings\kvartalnyy-kalendar-2027\assets --dst landings\kvartalnyy-kalendar-2027\assets\web
python landings\_scrape\build_calendar_config.py

cd landings\landing-blueprint-2
node render.js ..\kvartalnyy-kalendar-2027\config.json ..\kvartalnyy-kalendar-2027\dist

cd ..\..
python landings\validate_landing.py landings\kvartalnyy-kalendar-2027
```

Последняя команда обязательная: пока она падает, публиковать нельзя.

## Проверка собранного лендинга

`python landings/validate_landing.py <папка>`, 25 гейтов. Ловят
незамещённые плейсхолдеры, заглушку счётчика Метрики, цены при
`showPrices: false`, рассинхрон id между HTML и JS, битые якоря,
отсутствие юридического слоя, реквизиты без письменного подтверждения,
em-dash в видимом тексте, неэкранированные кавычки, дубли id,
отсутствующие фотографии в папке лендинга и в собранном `dist/`.

Гейты не видят вёрстку и не проверяют, грузятся ли картинки в браузере.
Для этого страница открывается локально и проходится руками.

## Три правила этой папки

1. **Каждое утверждение о факте ссылается на источник.** Файл
   сайта, выгрузка, дата. Без источника утверждение не пишется.
2. **Что опроверено и что нет, помечено явно.** Раздел «Где я не
   уверен» есть в каждом документе, где есть неопределённость.
3. **Правка генератора, а не артефакта.** Собранный `dist`
   правится через конфиг, иначе правка потеряется при следующей
   сборке.
