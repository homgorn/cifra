# Карта блоков лендинга по AIDA (референс)

Проверено на практике (лендинг «Цифра18», мерч-оффер). Не жёсткий шаблон —
адаптируется под тип бизнеса, но 7–10 содержательных блоков (без header/footer)
— нижняя граница, ниже неё AIDA не успевает отработать.

| # | Блок | Стадия | Обязателен? | Когда пропускать |
|---|------|--------|-------------|-------------------|
| 1 | Hero (оффер + фото/видео) | Attention | да | никогда |
| 2 | USP-полоска (3-4 карточки) | Attention/Trust | да | никогда |
| 3 | Способы/технологии работы | Interest | нет | если у бизнеса нет вариативности методов |
| 4 | Каталог/портфолио (реальные позиции) | Interest | да, если есть каталог | для услуги без каталога — заменить на "что входит в услугу" |
| 5 | Как проходит заказ/сотрудничество (3-5 шагов) | Interest→Desire | да | никогда — снимает неопределённость процесса |
| 6 | Квиз-калькулятор ИЛИ простой расчёт | Desire | да, если есть переменные параметры | для фикс. цены — заменить на явный прайс-блок |
| 7 | Цифры доверия (годы, клиенты, объёмы) | Desire | да | нет реальных цифр — не выдумывать, урезать до честных пунктов |
| 8 | FAQ (снятие возражений) | Desire | да | никогда |
| 9 | Форма + контакты + мессенджеры | Action | да | никогда |
| — | Кейсы/отзывы с цитатами | Desire | опционально | ТОЛЬКО если есть реальные тексты/скрины |

## Правило источников
Каждый пункт в блоках 2, 4, 5, 7, 9 должен быть прослеживаем до конкретного
куска исходника (сайт/презентация/прайс). Если факта нет — либо не включать
пункт, либо оставить явный TODO с пояснением, чего не хватает.
