# План выгрузок из Яндекс.Метрика: ЦИФРА18

**Источник:** Яндекс.Метрика (ID: 50863157)  
**Доступ:** нужен (у владельца)  
**Цель:** Baseline трафика, поведение, конверсии, сегменты для SEO/GEO стратегии

---

## 📊 Обязательные выгрузки (приоритет 1)

### 1. Источники трафика (Sources)
```
Отчёт: Стандартные отчёты → Источники → Сводка
Период: последние 12 месяцев (по месяцам)
Сегменты: Органический поиск / Яндекс / Google
Метрики: визиты, пользователи, отказы, глубина, время, цели, ecommerce
Формат: CSV / Excel
```
**Зачем:** Baseline органики, доля Яндекс/Google, сезонность, конверсия по каналам.

### 2. Поисковые запросы (Search Queries): если есть связка с Вебмастером
```
Отчёт: Стандартные отчёты → Источники → Поисковые запросы
Период: 12 месяцев
Метрики: показы, клики, CTR, позиция, визиты, цели
Формат: CSV
```
**Зачем:** Реальные запросы, приводящие трафик (не из GSC, а из Метрики).

### 3. Целевые события / Цели (Goals / Conversions)
```
Отчёт: Конверсии → Цели
Все настроенные цели: заявка, расчёт, звонок, чат, скачивание прайса
Период: 12 месяцев по неделям
Сегменты: по источникам (organic, direct, referral, social)
Формат: CSV
```
**Зачем:** Конверсия органики vs остальные каналы, стоимость лида.

### 4. Электронная коммерция (Ecommerce): если настроена
```
Отчёт: Электронная коммерция → Обзор / Товары / Транзакции
Период: 12 месяцев
Метрики: выручка, заказы, средний чек, конверсия, товары в заказе
Формат: CSV
```
**Зачем:** Привязка SEO трафика к реальным деньгам (ROI).

### 5. Поведение → Страницы входа (Landing Pages)
```
Отчёт: Контент → Страницы входа
Сегмент: Органический поиск
Период: 12 месяцев
Метрики: входы, отказы, время, цели, выручка
Формат: CSV (топ-500 URL)
```
**Зачем:** Какие страницы ловят органику, их качество, конверсия.

### 6. Вебвизор / Карты кликов: для топ-20 лендингов
```
Выборка: топ-20 страниц по органическому трафику
Задача: просмотреть 50-100 сессий на каждой
Вывод: проблемы UX, места ухода, работа форм/калькуляторов
```
**Зачем:** Качественный аудит конверсии (CRO).

## 📈 Дополнительные выгрузки (приоритет 2)

### 7. Долгосрочные интересы / Аудитория (Long-term interests)
```
Отчёт: Аудитория → Долгосрочные интересы
Сегмент: Органика
Формат: CSV
```
**Зачем:** Понимание ICP: кем являются посетители органики.

### 8. География (Geography)
```
Отчёт: Аудитория → География
Сегмент: Органика
Детализация: города Удмуртии + РФ
Формат: CSV
```
**Зачем:** Локальный SEO: где ищут, есть ли спрос в пригородах.

### 9. Устройства / Браузеры (Technology)
```
Отчёт: Технологии → Устройства / Браузеры
Сегмент: Органика
Формат: CSV
```
**Зачем:** Mobile-first индексация, приоритет оптимизации.

### 10. Параметры URL (UTM / OpenStat)
```
Отчёт: Источники → Параметры URL
Все UTM-метки за год
Формат: CSV
```
**Зачем:** Атрибуция, понимание какие кампании работают.
