# План выгрузок из Топвизор — ЦИФРА18

**Источник:** Топвизор (проект типографии Цифра)  
**Доступ:** у владельца  
**Цель:** Полная карта видимости: позиции, трафик, конкуренты, SERP-фичи, динамика

---

## 📊 Обязательные выгрузки (приоритет 1)

### 1. Позиции по всем ключам (Positions)
```
Модуль: Позиции → История / Текущие
Все ключи проекта (сколько их в проекте?)
Глубина: Топ-100 (или Топ-50)
Поисковые системы: Яндекс (Москва/Ижевск/Удмуртия), Google (Ижевск/РФ)
Устройства: Desktop + Mobile (отдельно!)
Период: вся история (или последние 12 месяцев)
Формат: CSV / XLSX
```
**Колонки, которые нужны:**
- Ключ, Частотность (Topvisor), URL-лендинг, Позиция (текущая), Позиция (предыдущая), Изменение, Топ (1/3/5/10/30/50/100), Трафик (forecast), URL в топе, SERP-фичи (сниппеты, карты, видео, картинки)

### 2. Группы ключей / Проекты (Keywords Groups)
```
Структура проекта в Топвизоре:
- Какие папки/группы созданы?
- Есть ли разметка по категориям (полиграфия, сувенирка, широкоформат, стенды, интерьер, инж. печать)?
- Есть ли теги: брендовые / небрендовые, коммерческие / информационные, локальные / общие?
```
**Зачем:** Понимание текущей семантики, поиск пробелов, каннибализация.

### 3. Конкуренты (Competitors) — Топвизор автоматически определяет
```
Модуль: Конкуренты → Общие / По ключам
Топ-10 конкурентов по видимости
Для каждого: общая видимость, общий трафик, пересечение ключей, уникальные ключи
Формат: CSV
```
**Зачем:** Benchmark, gap analysis, кто забирает трафик.

### 4. Видимость и трафик (Visibility & Traffic)
```
Модуль: Видимость → График / Таблица
Динамика за 12 месяцев: видимость (%), прогноз трафика, кол-во ключей в топе
Сегменты: по группам ключей, по ПС, по устройствам
Формат: CSV (по неделям/месяцам)
```
**Зачем:** Baseline роста, корреляция с апдейтами, сезонность.

### 5. SERP-фичи (SERP Features) — критично для GEO
```
Модуль: Позиции → SERP-фичи (есть в новых версиях Топвизора)
Для каждого ключа: какие фичи в выдаче (Карта, Сниппеты, Видео, Картинки, Товары, FAQ, People Also Ask, AI Overviews / Нейросеть)
Формат: CSV
```
**Зачем:** Понимание где можно попасть в расширенные сниппеты, AI Overviews, Карты.

### 6. Страницы-лендинги (Landing Pages) в топе
```
Модуль: Позиции → URL / Страницы
Какие URL сайта ранжатся, по скольким ключам, суммарный трафик
Формат: CSV
```
**Зачем:** Сравнение с Metrica landing pages, поиск страниц без трафика но в топе.

## 📈 Дополнительные выгрузки (приоритет 2)

### 7. История изменений позиций (Position History)
```
Для топ-200 ключей: ежедневная история за 90 дней
Формат: CSV (можно большой, сжимать)
```
**Зачем:** Анализ волатильности, выявление апдейтов, стабильность ранжирования.

### 8. Снимки SERP (SERP Snapshots) — для ключевых запросов
```
Топ-50 коммерческих ключей
Снимки выдачи (HTML/скриншоты) за последние 3 даты
```
**Зачем:** Ручной разбор SERP, анализ конкурентов, контентных блоков.

### 9. Локальные позиции (Local Pack / Карты)
```
Если есть отслеживание по Ижевск/Удмуртия отдельно:
Позиции в локальной выдаче (Карты, Справочник)
Отзывы, рейтинг, фото конкурентов
```
**Зачем:** Local SEO audit (seo-local skill).

### 10. Экспорт проекта (Project Export) — полный бэкап
```
Настройки → Экспорт проекта
Все ключи, группы, настройки, конкуренты, история
Формат: .tvz (внутренний) + CSV
```
**Зачем:** Бэкап, миграция, полный аудит офлайн.

## ❓ Вопросы к владельцу

1. **Сколько ключей в проекте?** (лимит тарифа)
2. **Есть ли разделение по ПС/устройствам/гео?** (Яндекс Ижевск, Яндекс РФ, Google Ижевск, Google РФ — отдельно?)
3. **Есть ли теги ключей?** (бренд/небренд, коммерч/инфо, локаль/общ)
4. **Настроен ли сбор SERP-фич?** (в тарифе может не быть)
5. **Есть ли доступ к API?** (ключ API в профиле)
6. **Какие конкуренты добавлены вручную?** (или только авто)
7. **Есть ли история более 1 года?** (нужна для трендов)
