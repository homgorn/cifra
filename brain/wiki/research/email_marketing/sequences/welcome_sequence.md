## 📧 Email Marketing Strategy Based on Incoming Emails

### 📊 Analysis of Incoming Emails Base

Based on the incoming emails analysis (izhcifra@yandex.ru + sales@), we identified:

|---|---|---|

| **Spam/Newsletters** | ~15% | Promo, spam, vendor emails |
| **Partner/Vendor** | ~5% | Paper suppliers, equipment service, SDEK |
| **Internal** | ~5% | Internal coordination |

## 🎯 Segmentation Strategy

| Segment | Criteria | Sequences |
|---|---|---|
| **New Leads** | Form submit, no quote yet | Welcome → Quote Nurture |
| **Quoted, No Order** | Quote sent >3 days ago | Quote Nurture |
| **First Order** | 1 order placed | Post-Order → Loyalty |
| **Repeat Customer** | 2+ orders | Loyalty + Reorder Reminders |
| **High Value** | LTV > 50k or 5+ orders | VIP care, personal manager |
| **Dormant 30d** | No activity 30d | Re-engagement 1 |
| **Dormant 60d** | No activity 60d | Re-engagement 2 |
| **Dormant 90d** | No activity 90d | Final Chance → Suppress |
| **Lost Deals** | Quote sent, rejected/ghosted | Win-back (quarterly) |

## 🛠 Technical Setup Checklist

### ESP Setup (Customer.io / Resend / SendGrid)
- [ ] Domain authentication (DKIM, SPF, DMARC)
- [ ] Subdomain: `mail.cifra18.ru`
- [ ] Suppression list import
- [ ] Webhook endpoints for events

### Segments to Create
```sql
-- New Leads (last 30 days, no order)
SELECT * FROM contacts WHERE created_at > NOW() - INTERVAL 30 DAY AND orders_count = 0;

-- Quoted No Order (quote sent > 3 days, no order)
SELECT * FROM contacts WHERE last_quote_at > NOW() - INTERVAL 30 DAY AND orders_count = 0;

-- Dormant 30/60/90
SELECT * FROM contacts WHERE last_activity < NOW() - INTERVAL 30 DAY AND orders_count > 0;
-- ... 60, 90 days
```

### Webhooks to Implement
- `lead.created` → Trigger Welcome Sequence
- `quote.sent` → Trigger Quote Nurture
- `order.placed` → Trigger Post-Order Sequence
