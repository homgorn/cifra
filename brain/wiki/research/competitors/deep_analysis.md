## 🎯 ОППОРТУНИТИ ДЛЯ ЦИФРА18 (Что добавить/улучшить)

### 1. КРИТИЧНО (Phase 0-1)
- [ ] **SDEK калькулятор в виджете калькулятора** — real-time тарифы + сроки
- [ ] **Онлайн-оплата (ЮKassa/Тинькофф/СБП)** — препай 50-100%
- [ ] **Онлайн-калькулятор цен** для всех категорий (как Printio, но для полиграфии)
- [ ] **Schema.org shippingDetails на всех PDP** — SDEK тарифы в SERP
- [ ] **SDEK виджет трекинга** в личном кабинете/email/SMS

### 2. ВЫСОКИЙ ПРИОРИТЕТ (Phase 1-2)
- [ ] **Онлайн-редактор макетов** для визиток/листовок/мерча (как Printio)
- [ ] **Мерч-каталог 50+ SKU** (кружки, футболки, термосы, рюкзаки, брелоки, пауэрбанки)
- [ ] **Программатик SEO: Service×City (200 стр)** — "Визитки Москва СДЭК", "Баннеры СПб доставка"
- [ ] **Schema.org на всех страницах** — Organization, LocalBusiness, Product, Service, FAQ, Breadcrumb
- [ ] **SDEK трекинг виджет** в личном кабинете + email/SMS уведомления
- [ ] **Кейсы/Портфолио** — 20+ детальных кейсов с фото, метриками, отзывами

### 3. СРЕДНИЙ ПРИОРИТЕТ (Phase 2-3)
- [ ] **API для партнеров** (агентства, дизайнеры, франчайзи) — комиссия 10-15%
- [ ] **B2B портал** — корпоративные аккаунты, объемные скидки, единый биллинг
- [ ] **Программатик: Materials (50), Glossary (200), FAQ (100), Comparisons (50)**
- [ ] **Онлайн-редактор для мерча** (как Printio, но для полиграфии + мерч)
- [ ] **Корпоративные мерч-планы** — подписка 4 поставки/год, дизайн бесплатно, СДЭК бесплатно
