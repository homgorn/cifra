## 💪 Сильные стороны (Threats для ЦИФРА)

1. **Физическая сеть**: 14 точек выдачи в Ижевске (walk-in traffic)
2. **Доминирование в 2ГИС/Яндекс.Картах**: рейтинг 4.5-4.9, 800+ отзывов
3. **Бренд "Контур"**: узнаваемый локальный бренд (Контур.Экстерн, Контур.Фокус)
4. **Скидки от тиража**: понятная ценовая политика для B2B
5. **Фотопечать как якорь**: высокий чек, повторные заказы
6. **14 точек самовывоза**: удобно для клиентов
7. **Долгая история**: доверие, стабильность

---

## 🎯 Слабые стороны (Opportunities для ЦИФРА)

1. **Нет калькулятора цен**: только форма "Заказать"
2. **Нет онлайн-оплаты**: только наложенный/перевод менеджеру
3. **Нет онлайн-редактора макетов**: загрузка файла + проверка менеджером
4. **Нет мерча** (футболки, термосы, рюкзаки, брелоки)
5. **Нет широкоформатной печати** (баннеры, роллапы, стенды)
5. **Нет инж. печати** (чертежи, сканирование А0)
6. **Нет SDEK по РФ**: только Ижевск
7. **Нет онлайн-оплаты / SDEK калькулятор / трекинг**
8. **Нет JSON-LD / Schema.org**: слабая SEO-структура
9. **Нет блога/экспертного контента**: нет SEO-трафика по инфо-запросам
10. **Низкий рейтинг в 2ГИС у ЦИФРА (4.2)** vs Контур-Фото (4.9): репутационный гэп
11. **Нет программатик SEO**: нет Service×City страниц
12. **Нет API для партнеров**: нет B2B интеграций

## 🎯 Стратегия против Контур-Фото

### Краткосрочно (1-2 мес):
1. **Phase 0 фиксы**: закрыть технические гэпы (схема, каноникал, H1, мета)
2. **SDEK калькулятор в виджете**: уникальное УТП vs Контур-Фото
3. **Отзывы 2ГИС**: кампания "Оставьте отзыв, получите скидку 5%" к 100+ отзывов
4. **Service×City лендинги**: "Визитки Москва СДЭК", "Баннеры СПб доставка"

### Среднесрочно (3-6 мес):
1. **Мерч-каталог 50+ SKU**: то, чего нет у Контур-Фото
2. **Онлайн-редактор визиток/мерча**: УТП vs ручная загрузка файлов
3. **Service×City программатик**: 200+ страниц под коммерческие запросы по РФ
3. **Кейсы B2B**: "Как мы напечатали мерч для сети кофеен за 3 дня с доставкой СДЭК в 5 городов"

### Долгосрочно (6-12 мес):
1. **B2B портал**: корпоративные аккаунты, объемные скидки, единый биллинг
2. **API для партнеров**: агентства/дизайнеры/франчайзи
2. **Корпоративные мерч-планы**: подписка на мерч с доставкой СДЭК
