## 💪 Сильные стороны

1. **Полный цикл "под ключ"**: от дизайна до монтажа наружной рекламы
2. **Экспертиза в наружной рекламе**: разрешения, места, монтаж
3. **Дизайн-команда**: сильный креатив, фирменные стили
5. **Комплексные предложения**: "под ключ" для открытий/событий

---

## 🎯 Слабые стороны

1. **Нет собственного производства полиграфии**: аутсорс на типографии (наценка 30-50%)
2. **Нет калькулятора цен**: только ручной расчет менеджером
3. **Нет онлайн-оплаты / калькулятора СДЭК**
3. **Нет мерча / широкоформатной печати своего производства**
4. **Агентская наценка**: цена для клиента выше на 30-50%
4. **Нет API / онлайн-калькулятора / SDEK**
5. **Фокус на B2B среднего/крупного**: малый бизнес не в фокусе

---

## 🎯 Возможности для ЦИФРА

| Слабость SMART | Возможность ЦИФРА |
|---|---|
| Нет калькулятора → ручной расчет | Онлайн-калькулятор за 30 сек |
| Агентская наценка 30-50% | Прямое производство = ниже цена |
| Нет мерча своего производства | Мерч-каталог 50+ SKU + калькулятор |
| Нет SDEK по РФ | SDEK виджет + доставка по РФ |
| Нет онлайн-оплаты | ЮKassa/СБП/Тинькофф |

---

## 🎯 Стратегия против SMART

**Позиционирование:** "Прямое производство без агентских наценок. Считаете стоимость сами за 30 секунд. Доставка СДЭК по России."

**Таргет:** Малый бизнес, которым не нужен полный дизайн-консалтинг, а нужны быстрые, дешевые, качественные полиграфия/мерч с доставкой.
