## 📊 Market Analysis

### Total Addressable Market
- **Russian corporate merch market:** ~15-20 млрд руб/год, рост 15-20% в год
- **ЦИФРА18 Position:** Локальный игрок с производством (преимущество: цена, качество, скорость), слабый в digital/merch
- **Current merch revenue share:** 5-10% → Target 35% (12 months)

### Key Competitors

| Competitor | Merch SKU | Tech Stack | Weakness | Threat Level |
|---|---|---|---|---|
| **Printio** | 150+ | POD + API + Drag&Drop Editor | Нет офсета, нет широкоформата, качество POD ниже офсета | 🔴 Critical |
| **RuPrint** | 352 (souvenirs) | Офсет + Цифра + Широкоформат | Нет калькулятора, нет API, нет мерча (текстиль) | 🔴 High |
| **Printful** | 300+ | POD + API + Shopify/WooCommerce | Нет локального производства в РФ | 🟠 Medium-High |
| **Canva Print** | Templates | Design-first | Нет производства, слабое SEO для мерча | 🟡 Medium |
| **Wildberries/Ozon** | Marketplace | Мерч через продавцов | Нет контроля качества, нет брендинга | 🟠 Medium |

## 🚀 Marketing Opportunities

### 1. Product-Led Growth
- **Конструктор мерча на сайте** (как Printio): Drag&Drop редактор для B2B
- **Калькулятор мерча с мгновенным расчетом + СДЭК**
- **Онлайн-редактор макетов для мерча** (Drag&Drop как Printio)
- **API для B2B партнеров** (агентства, франчайзи, HR-бренды)
