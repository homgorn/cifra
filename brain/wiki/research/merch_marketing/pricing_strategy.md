# Pricing Strategy — ЦИФРА18 Merch

**Date:** 2026-09-12  
**Goal:** Maximize margin while maintaining competitive position vs Printio, RuPrint, Printful

---

## 🎯 Pricing Philosophy

| Principle | Application |
|---|---|
| **Value-based pricing** | Цена = воспринимаемая ценность (бренд, качество, уникальность), не cost+markup |
| **Tiered pricing** | 5 тиров от Starter (100₽) до Premium Boxes (15,000₽) |
| **Volume discounts** | Автоматические скидки от тиража (видно в калькуляторе) |
| **Bundling discount** | Кросс-селл скидки 10-20% при покупке наборов |
| **B2B pricing** | Отдельный прайс для корпоративных клиентов (NET-30, объемные скидки) |

## 🎯 Dynamic Pricing Rules (для калькулятора)

```javascript
// Псевдокод логики ценообразования
function calculatePrice(sku, quantity, material, printMethod, deliveryCity) {
  let basePrice = getBasePrice(sku, material, printMethod);
  
  // Volume discount
  let discount = getVolumeDiscount(quantity);
  
  // Material multiplier
  let materialMultiplier = getMaterialMultiplier(material);
  
  // Print method multiplier
  let printMultiplier = getPrintMethodMultiplier(printMethod);
  
  // Delivery
  let delivery = calculateSDEK(BASE_CITY, deliveryCity, weight, dimensions);
  
  // Total
  let unitPrice = basePrice * materialMultiplier * printMultiplier * (1 - discount);
  let total = unitPrice * quantity + delivery;
  
  return {
    unitPrice: Math.round(unitPrice),
    total: Math.round(total),
    delivery: Math.round(delivery),
    discount: Math.round(discount * 100) + '%',
    margin: calculateMargin(sku, unitPrice)
  };
}
```
