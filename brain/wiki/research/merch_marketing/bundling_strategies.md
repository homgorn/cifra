## 🏗️ Bundle Builder Logic (Dynamic)

### Algorithm for Custom Bundle Builder

```python
def build_custom_budget(budget, recipient_type, occasion):
    """
    Generates optimal bundle within budget
    """
    catalog = load_merch_catalog()
    
    # Filter by budget
    affordable = [item for item in catalog if item.cost <= budget * 0.8]
    
    # Score items by relevance
    scored_items = []
    for item in affordable:
        score = 0
        if item.tags & occasion_tags: score += 10
        if item.tags & recipient_type_tags: score += 15
        if item.cross_sell_potential > 0.7: score += 10
        if item.margin > 0.5: score += 5
        scored_items.append((item, score))
    
    # Greedy selection for max value within budget
    scored_items.sort(key=lambda x: x[1], reverse=True)
    
    selected = []
    remaining_budget = budget * 0.85  # leave 15% for packaging/shipping
    
    for item, score in scored_items:
        if item.cost <= remaining_budget:
            selected.append(item)
            remaining_budget -= item.cost
            
            # Add cross-sell
            cross_sells = get_cross_sells(item.sku)
            for cs in cross_sells[:2]:
                if cs.cost <= remaining_budget * 0.3:
                    selected.append(cs)
                    remaining_budget -= cs.cost
    
    return build_bundle_response(selected)

# Example outputs:
# Budget 3000₽, New Employee, Welcome → 
#   Футболка (850) + Кружка (550) + Блокнот (650) + Ручка (120) + Стикерпак (300) + Бейдж (180) = 2570₽
#   Box + Shipping = 3000₽

# Budget 10000₽, VIP Client, Anniversary
#   Премиум худи (2800) + Термос премиум (1500) + Кружка керамика премиум (800) 
#   + Блокнот премиум (1200) + Ручка гравировка (500) + Подарочная коробка (500) = 10000₽
```
