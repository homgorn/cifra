## 🎯 Этап 2: Стратегия по интентам (Intent Strategy)

### Интент-карта для каждой статьи
| Интент | Признаки | Структура статьи | Schema | CTA |
|---|---|---|---|---|
| **Informational** (узнать) | "что такое", "как сделать", "разница", "виды" | Ответ в H2 → детали → примеры → FAQ | Article + FAQPage | "Рассчитать стоимость" (калькулятор) |
| **Commercial** (выбрать/купить) | "цена", "заказать", "купить", "лучшие", "топ" | Сравнительная таблица → цены → калькулятор → заказ | Product/Service + FAQPage | "Заказать расчёт" (форма) |
| **Transactional** (заказать сейчас) | "заказать визитки Ижевск", "печать баннеров срочно" | Минимальный текст → калькулятор → форма → гарантии | Product + Offer | "Заказать в 1 клик" |
| **Navigational** (найти бренд) | "типография цифра ижевск", "цифра18 контакты" | Контакты, карта, реквизиты, фото производства | LocalBusiness + ContactPage | "Позвонить / Написать" |

### Правила оптимизации под интент
1. **H2 = вопрос пользователя** (из People Also Ask, Топвизор, Яндекс.Подсказки)
2. **Первый абзац после H2 = прямой ответ** (40-60 слов, без воды)
3. **Таблицы сравнения** для commercial intent
4. **Списки (ul/ol)** для пошаговых инструкций
5. **Цифры с источниками** ("по данным ГОСТ...", "по нашим 500+ заказам...")
6. **FAQ блок** в конце (3-5 вопросов) → `FAQPage` schema
7. **Внутренние ссылки** на money pages (каталог Bitrix) с анкорами-ключами

## 🤖 Этап 4: GEO-оптимизация (AI Citability)

### 5-пилярная рубрика (geo-visibility skill)
| Пиляр | Что делать в статье |
|---|---|
| **Answer-first** | H2 = вопрос, 1-й абзац = ответ (40-60 слов) |
| **Stats & Quotes** | Минимум 2-3 цифры с источником на статью |
| **Tables & Lists** | Минимум 1 таблица сравнения или маркированный список на статью |
| **Question Headings** | Все H2/H3 формулируются как вопросы пользователя |
| **E-E-A-T Signals** | Автор (технолог/дизайнер), дата обновления, ссылки на кейсы, фото производства |

### Чек-лист GEO для каждой статьи
- [ ] H1 содержит главный ключ + локация (если применимо)
- [ ] Каждый H2: вопрос из People Also Ask / Яндекс.Подсказки
- [ ] Первый абзац после H2: самодостаточный ответ
- [ ] Есть таблица сравнения / список / нумерованная инструкция
- [ ] Есть 2+ цифры с указанием источника
- [ ] Есть блок FAQ (3-5 вопросов) с `FAQPage` schema
- [ ] Есть `Article` / `BlogPosting` JSON-LD с author, datePublished, dateModified
- [ ] Есть внутренние ссылки на money pages (Bitrix каталог) с анкорами-ключами
- [ ] Есть внешние ссылки на авторитетные источники (ГОСТ, производители материалов)
- [ ] Картинки имеют осмысленные alt (ключ + описание)
- [ ] Нет em-dash (—), заменены на запятые
- [ ] llms.txt включает эту статью (после переноса на WP)

## 📝 Этап 5: Процесс переработки (Content Factory)

### Шаблон брифа для копирайтера (seo-content-brief skill)
```markdown
# Бриф: [Название статьи]
**Целевой URL (WP):** /blog/[slug]/
**Кластер:** [Подготовка макетов / Технологии / Материалы...]
**Интент:** Informational / Commercial
**Главный ключ:** [ключ] (частотность Топвизор: X)
**LSI ключи:** [список 5-10]
**Конкуренты в топе:** [URL 1, URL 2, URL 3] - их длина, структура
**People Also Ask:** [вопросы из Яндекс/Google]
**Структура (H2):**
1. Что такое [тема]? (ответ 50 слов)
2. Виды/Типы [темы] (таблица сравнения)
3. Как выбрать [тему] для [задачи]? (чек-лист)
4. Ошибки при [действии] (список)
5. FAQ (3-5 вопросов)
**Требования:**
- Объем: 1500-2500 слов
- Тон: экспертный, простыми словами, без воды
- Автор: [Имя технолога/дизайнера] + фото + роль
- Фото: 3-5 фото с производства (доступ к базе фото)
- Ссылки: 3-5 внутренних на каталог Bitrix, 1-2 внешних на ГОСТ/производителей
- Дедлайн: [дата]
```

### Поток работы (Content Factory)
```
1. SEO-специалист → Бриф (из таблицы решений) → в Notion/Asana
2. Копирайтер/Технолог → Черновик в Google Docs (4-6 часов на статью)
3. Редактор (writing-coach) → Правка: интент, сущности, GEO, анти-AI-slop (1-2 часа)
4. SEO-проверка → seo_audit.py на черновике + чек-лист GEO
5. Публикация на WP → Yoast/RankMath → заполнение мета, схема, FAQ
6. Индексация → IndexNow API + GSC/Яндекс.Вебмастер
7. Соцсети → Дзен/ВК/Shorts анонс (SMM план)
8. Мониторинг → через 2 недели: позиции, трафик, конверсия
```
