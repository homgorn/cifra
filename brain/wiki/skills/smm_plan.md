## 🎯 Стратегия по платформам

### 1. Яндекс.Дзен (Приоритет #1 для GEO + SEO)
**Почему:** Яндекс индексирует Дзен-статьи, они попадают в выдачу, Нейросеть Яндекса цитирует их, трафик на сайт.

| Формат | Частота | Контент | CTA |
|---|---|---|---|
| **Статья-экспертная** (1500-3000 зн) | 2 в неделю | Глубокий разбор: "Как выбрать бумагу для визиток", "Технологии печати баннеров", "Ошибки в макетах" | Ссылка на статью в WP блог / калькулятор на Bitrix |
| **Кейс-стори** | 1 в неделю | "Как напечатали 5000 визиток за 3 часа для риелторов", "Брендированный мерч для кофейни" | Ссылка на кейс в WP /cases/ |
| **Короткий совет** (300-500 зн) | 3 в неделю | "Почему крафт дороже офсета", "Разница между ламинацией и УФ-лаком" | Ссылка на глоссарий / материал в WP |
| **Подборка/Топ** | 1 в 2 недели | "Топ-5 материалов для уличной рекламы", "7 идей мерча за 100 руб" | Ссылка на коллекцию в каталоге Bitrix |

**Техническое:**
- Канал: `zen.yandex.ru/id/XXXX` (создать под брендом)
- RSS импорт из WP блога (плагин "Yandex Zen для WordPress" или ручной)
- UTM: `utm_source=zen&utm_medium=organic&utm_campaign=article_slug`
- Профиль: лого, обложка, описание с ключами "типография Ижевск", "печатная продукция"

## 🔄 Контентная фабрика (Workflow)

### Источники контента (Content Sources)
1. **Блог WP** → адаптация под Дзен/ВК (1 статья = 1 Дзен + 3 ВК поста + 3 Shorts)
2. **Кейсы (WP /cases/)** → ВК пост + Shorts + Дзен кейс-стори
3. **Глоссарий/Материалы (WP)** → короткие советы ВК/Дзен + Shorts
4. **Производство (фото/видео)** → контент для Reels/Клипов/Сторис
5. **FAQ от менеджеров** → посты "Вопрос-ответ" + глоссарий
6. **Отзывы клиентов** → социальное доказательство во всех каналах

### Процесс производства (неделя)
```
Понедельник: Планирование темы недели + сбор сырых материалов (фото/видео с производства, ответы менеджеров)
Вторник: Написание текстов (Дзен статья + 3 ВК поста) + сценарии Shorts
Среда: Съемка видео/фото (1-2 часа на производстве) + монтаж Shorts (6 шт.)
Четверг: Публикация Дзен статьи + запланированные ВК посты + Shorts
Пятница: Кейс-пост в ВК + Дзен кейс-стори + аналитика недели
Суббота/Воскресенье: Сторис, ответы в комментариях, сбор UGC
```

### Инструменты
| Задача | Инструмент |

| Тексты | Google Docs / Notion → копипаст |

| Аналитика | Встроенная (Дзен, ВК) + GA4/Метрика UTM |

## 🔗 Интеграция с SEO/GEO

| SEO/GEO задача | SMM действие |
|---|---|
| **Индексация новых страниц** | Анонс в Дзен/ВК сразу после публикации в WP → быстрая индексация |
| **Брендовые сигналы** | Регулярные упоминания "Типография Цифра Ижевск" во всех постах |
| **Entity consistency** | Единый НПП (Имя, Телефон, Адрес) в профилях всех соцсетей |
| **Ссылки (Link building)** | Профиль ВК → ссылка на сайт; Дзен → ссылки в статьях; YouTube → описание |
| **UGC для/schema** | Отзывы в ВК → микроразметка Review на сайте |
| **AI visibility** | Дзен-статьи попадают в Яндекс Нейросеть → цитируемость бренда |
