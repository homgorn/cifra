# Яндекс Бизнес, Карты и Услуги: есть ли API

**Дата проверки:** 2026-09-27. Проверено по документации Яндекса и фактическими
запросами к API Метрики.

## Короткий ответ

Отдельного публичного API у Яндекс Бизнеса нет, но почти все нужные цифры
лежат в счётчике карточки в Яндекс Картах, и он доступен через API Метрики.
Отдельно доступны: геокодирование (HTTP-сервис Яндекса) и Places API в песочнице
(без ключа, только демо-данные).

## Чего в API нет

- Рейтинг и динамика отзывов: только через парсер или руками из кабинета.
- Статистика кликов по конкретным кнопкам карточки кроме целей: `ym:s:goal`
  отдаёт только те цели, что настроены в счётчике.
- Профиль на `uslugi.yandex.ru`: это отдельный счётчик, к нему надо запросить
  доступ у владельца кабинета.
- Выгрузка в формате Яндекс Бизнеса (XLS со всеми полями): API не отдаёт,
  кабинет выгружает вручную.

## Смежные сервисы, которые есть

- **Геокодирование:** `https://geocode-maps.yandex.ru/1.x/`, работает с
  ключем Яндекса, отдаёт координаты и адрес. Полезно для проверки адресов
  в 2ГИС и на сайте.
- **Places API:** официальная замена Google Places, в песочнице работает без
  ключа с демо-данными, для боевого режима нужен ключ и заявка.
- **Reviews API:** есть только у агрегаторов (2ГИС, Яндекс Отзывы через
  партнёрские виджеты), прямого API нет.

## Вывод и что делать

1. Расширить цели в счётчике карточки: завести цели на каждую кнопку и на
   звонок с сайта из карточки, тогда в Метрике появится полная картина.
2. Загружать эти звонки в счётчик сайта офлайн-конверсией с указанием
   источника «Карты», иначе канал остаётся невидимым в отчёте по выручке.
3. Отзывы и рейтинг вести вручную раз в неделю, это 10 минут и заметный
   эффект на звонки.
4. Страницу услуг в `uslugi.yandex.ru` закрыть или обновить: сейчас она даёт
   трафик, но не связана с сайтом.
