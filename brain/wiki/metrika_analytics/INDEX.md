## 🎯 Главные выводы

### ✅ Что работает хорошо
1. **Карточка организации в Картах** — 2 446 визитов, главный внешний канал.
2. **Поисковый трафик качественный** — отказы 37% против 75% по сайту, глубина 3.06.
3. **Профиль на uslugi.yandex.ru** — 615 визитов, живой канал.
4. **Рост 2026** — пик в августе 2026 (3 532), отказы в Q3 упали до ~50%.

### 🔴 Критические проблемы
1. **Один счётчик на несколько доменов** — в статистику льются стейджинг beget.tech и чужой запрос «агм гидравлика». Данные загрязнены.
2. **Только 3.8% входов — страницы сайта**, остальное — хосты сервисов Яндекса (карты, навигатор, погода-уровень). Сайт как точка входа почти не работает.
3. **Поиск даёт 4.2% визитов** — органике нечего масштабировать без закрытия проблем Вебмастера.
4. **Мусорные запросы** («яндекс карты», «карты», «карта» — 109 визитов) — путать ядро, исключить из SEO.

### 🟠 Проблемы высокого приоритета
1. **Админка Битрикса во входах** — 283 визита, внутренний трафик не отфильтрован.
2. **Стейджинг в индексе/статистике** — cifra.salelib3.beget.tech: 460 визитов, 148 URL.
3. **Отказы 75%** по сайту — разбирать по источникам (карты дают быстрые касания).

## 🚀 Следующие шаги

1. **Разделить счётчики/фильтры** — отдельный счётчик на прод, фильтр админки и стейджинга (см. 05_Actions).
2. **Добить Вебмастер-проблемы** — органика 4.2%, расти некуда без индексации (`webmaster_analytics/`).
3. **Качать карточки** — Maps org + uslugi.yandex.ru дают больше сайта: отзывы, фото, услуги.
4. **Почистить семантику** — мусорные запросы в минус-словарь ядра.
