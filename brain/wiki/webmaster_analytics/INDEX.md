## 🎯 Главные выводы

### ✅ Что работает хорошо
1. **Брендовые запросы** — позиции 1-2: "типография цифра", "цифра ижевск", "цифра 18"
2. **Коммерческие запросы** — ТОП-3 по визиткам, календарям, кружкам, бейджам
3. **Низкочастотные_LONG_TAIL** — многие специфические запросы на позиции 1-2
4. **Новости/Блог** — 140 страниц в поиске, 9 searchable (мало, но есть база)

### 🔴 Критические проблемы
1. **PARSE_ERROR: 251 страница (35%)** — робот не может прочитать контент
2. **DUPLICATE: 128 страниц (18%)** — массовые дубли из-за `detail.php?ID=`, UTM, слешей
3. **Sitemap 404** — все 23 sitemap в robots.txt не работают (подтверждает аудит)
4. **REDIRECT_NOTSEARCHABLE: 89** — цепочки редиректов теряют вес
5. **Только 142 searchable из 717** — коэффициент индексации **19.8%** (норма 60%+)

### 🟠 Проблемы высокого приоритета
1. **LOW_DEMAND / BAD_QUALITY: 22 страницы** — контент не устраивает алгоритм
2. **Множество страниц с title="Каталог", meta="Description"** — шаблонные заглушки
3. **/shop/ раздел: 388 индексированных, 0 downloaded, 24 searchable** — технический мусор
4. **/detail.php: 28 индексированных, 11 downloaded, 2 searchable** — параметрические дубли

## 🔍 Методология (кратко)

Согласно [справке Яндекс.Вебмастера](https://yandex.com/dev/webmaster/doc/ru/reference/errors):

| Статус | Значение | Действие |
|---|---|---|
| **SEARCHABLE** | В поиске — всё ок | Поддерживать, улучшать сниппеты |
| **DUPLICATE** | Дубликат другой страницы | Поставить `rel=canonical` или 301 на основную |
| **PARSE_ERROR** | Робот не смог распарсить | Проверить HTML, кодировку, JS-рендеринг |
| **LOW_DEMAND** | Низкий спрос/качество | Улучшить контент, добавить уникальность, E-E-A-T |
| **BAD_QUALITY** | Низкое качество по алгоритму | Глубокая переработка контента |
| **HTTP_ERROR** | Ошибка сервера (5xx, таймаут) | Исправить сервер/хостинг |
| **REDIRECT_NOTSEARCHABLE** | Редирект, цель в поиске | Убедиться что цель качественная, убрать цепочки |
| **OTHER** | Нет актуальных данных | Запросить переобход |
