**Как получено.** Таблицу метрик ниже собирает
`scripts/export/build_wm_data.py` по правилам из `CLUSTER_RULES`, руками
она не размечается. Числа берутся из
`reports/cifra18-audit/js/wm-data.js`, который собирается из выгрузки
панели Вебмастера. Проверка: `python scripts/export/facts.py`.

**Что важно не перепутать.** В выгрузке 535 строк, из них 43 это телефоны и
длинные описания товаров, то есть мусор. Реальных запросов 492. Из них 439
разложены по 22 кластерам, а 53 лежат в корзине «Прочие» и ждут разбора.

подписью.

**Инструменты для пересборки.** Яндекс.Вебмастер «Подбор запросов»,
Keys.so, Serpstat, кластеризация через LDA и BERT.

## 🔗 Внутренняя перелинковка (схема)

```
ГЛАВНАЯ (/)
├── H1: Типография «Цифра» — печать в Ижевске
├── Блок «Услуги» → ссылки на 7 основных разделов каталога

├── Блок «Статьи» → 3 последние экспертные статьи
└── Блок «Кейсы» → 3 портфолио проекта

КАТЕГОРИИ (/catalog/*)
├── H1: Название категории + «в Ижевске»
├── SEO-текст (200-300 слов) под H2 «Почему заказывают у нас»
├── Товары/Подкатегории с анкорами: «Купить [товар]», «Цена на [товар]»
├── Хлебные крошки + JSON-LD BreadcrumbList
├── Ссылки на статьи блога по теме
├── Ссылки на сравнения (X vs Y)
└── Ссылки на локальные лендинги

ТОВАРЫ (/catalog/*/item/)
├── H1: Название + цена/калькулятор
├── SEO-описание (уникальное, 300+ слов)
├── FAQ schema (5-7 вопросов)
├── Фото/видео производства
├── Отзывы (AggregateRating)
├── Перелинковка: «Смотрите также», «Похожие товары», «Статьи по теме»
└── CTA: калькулятор, заказ обратного звока, кнопка «В корзину»

СТАТЬИ (/blog/*)
├── H1: Вопрос/проблема пользователя
├── Lead-абзац (ответ в 40-60 слов)
├── Структура: H2-вопросы, списки, таблицы, фото
├── E-E-A-T: автор, дата, экспертность, кейсы
├── Перелинковка: товары, категории, другие статьи
└── CTA: калькулятор, заказ консультации, скачать чек-лист

СРАВНЕНИЯ (/comparison/*)
├── H1: «X vs Y: что выбрать для [задачи]»
├── Таблица сравнения (5-7 параметров)
├── Вердикт: «Выбирайте X если... Y если...»
├── Ссылки на обе категории товаров
└── CTA: калькулятор/консультация
```
