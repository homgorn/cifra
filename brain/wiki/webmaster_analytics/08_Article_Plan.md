## 📝 Структура статьи (Template для копирайтера)

### Pillar-статья (2500+ слов)
```
H1: Технические требования к макетам для печати: полное руководство 2027
Lead (40-60 слов): Ответ на главный вопрос - «Какие требования к макету, чтобы печать получилась качественной?»
  → «Для качественной печати макет должен быть в CMYK, 300 dpi, с вылетами 3-5 мм, шрифты в кривых, без RGB и скрытых слоёв.»

H2: Общие требования ко всем видам печати
  H3: Цветовая модель: только CMYK
  H3: Разрешение: 300 dpi для растра, вектор для текста/логотипов
  H3: Вылеты (bleed): 3 мм для визиток/листовок, 5 мм для широкоформата
  H3: Безопасная зона: важные элементы не ближе 5 мм к краю
  H3: Шрифты: в кривых (outlines) или прикреплены
  H3: Слои: без скрытых, заблокированных, пустых слоёв

H2: Требования по типам продукции (таблица)
  | Продукт | Формат | Вылеты | Цвет | Особенности |
 | Визитки | 90×50 мм | 3 мм | CMYK / Пантоны | Тиснение/фольга - отдельный слой |
 | Листовки А5 | 148×210 мм | 3 мм | CMYK | Двусторонние - 2 файла |
 | Календари | Разные | 5 мм | CMYK | Пружина/скоба - отступ 10 мм |
  | Широкоформат | До 1.6м | 5-10 мм | CMYK | 150 dpi достаточно, вектор лучше |
 | Кружки/Сувенирка | По шаблону | - | CMYK | Область печати строго по шаблону |

H2: Частые ошибки и как их исправить
  (5-7 пунктов с фото «Было/Стало»)

H2: Чек-лист перед отправкой (скачиваемый PDF)
  [Кнопка скачивания за email → лид-магнит]

H2: Видео-гайд (3 минуты) - встраивание YouTube/Рутюб

H2: FAQ (Schema FAQPage)

  A: Нет, цвет изменится. Конвертируйте в CMYK заранее.
  ...

H2: Ссылки на шаблоны макетов (Скачать .psd/.ai/.cdr)
  → Перелинковка на коммерческие страницы

JSON-LD: Article + HowTo (для чек-листа) + VideoObject
```

## 🎯 SEO-бриф для копирайтера (Checklist)

- [ ] **H1** содержит главный ключ + локация (Ижевск) + УТП
- [ ] **Lead-параграф** отвечает на вопрос за 40-60 слов (Answer-First)
- [ ] **Минимум 3 H2** сформулированы как вопросы пользователя
- [ ] **Минимум 1 таблица** или **2 списка** (ul/ol/dl)
- [ ] **Минимум 2 статистики/цифры** с источниками (ГОСТ, внутренние данные, эксперт)
- [ ] **E-E-A-T сигналы:** автор (имя, фото, роль), дата публикации/обновления, экспертный тон
- [ ] **Перелинковка:** 3-5 ссылок на коммерческие страницы, 2-3 на другие статьи
- [ ] **CTA:** понятное, релевантное (калькулятор, заказ, скачать, консультация)
- [ ] **Изображения:** уникальные фото производства, alt с ключами, WebP, lazyload
- [ ] **JSON-LD:** Article + (HowTo/FAQ/VideoObject/ComparisonPage)
- [ ] **og:image** 1200×630 с заголовком статьи
- [ ] **Нет em-dash (—)**: только запятые и точки
- [ ] **Проверка:** Глаvrd/Тургенев (тошнота < 5), уникальность > 90%
