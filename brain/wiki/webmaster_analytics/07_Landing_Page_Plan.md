## 📝 Контент-брифы для копирайтеров (по приоритетам)

### Бриф 1: Подкатегории визиток (3 страницы)
- **Ключи:** визитки на дизайнерском картоне, срочная печать визиток, печать белым тонером
- **Объём:** 300-400 слов уникального текста каждая
- **Элементы:** калькулятор, таблица материалов, фото тиражей, FAQ (5-7), отзывы
- **JSON-LD:** Product/Service + OfferCatalog + FAQ

### Бриф 2: Подкатегории широкоформат (3 страницы)
- **Ключи:** печать на баннере, печать на пленке, печать постеров
- **Объём:** 300-400 слов
- **Элементы:** калькулятор м², таблица материалов (фронтлит/бэклит/пленка), фото работ, FAQ
- **JSON-LD:** Service + Offer

### Бриф 3: Сравнения (2 страницы — приоритет)
- **Ключи:** информационные (нет в Вебмастере, но высокий CTR)
- **Объём:** 800-1200 слов + таблица 7-10 параметров
- **Элементы:** экспертный вердикт, фото/видео, CTA на обе категории
- **JSON-LD:** ComparisonPage (custom) + FAQ

### Бриф 4: Локальные лендинги (3 страницы — приоритет)
- **Ключи:** коммерческие + гео
- **Объём:** 400-500 слов уникального про район/районы
- **Элементы:** карта Яндекс, NAP, фото производства/офиса, кейсы по району, отзывы с гео
- **JSON-LD:** LocalBusiness + Service + Review

### Бриф 5: Статья "Тех требования к макетам" (1 страница — база для всех)
- **Ключи:** информационные, long-tail
- **Объём:** 2000+ слов
- **Элементы:** PDF чек-лист (скачивание за email), видео 3 мин, таблицы спеков по продуктам
- **JSON-LD:** Article + HowTo (для чек-листа)

## 🔧 Технические требования к шаблонам

| Элемент | Обязателен | Где реализовать |
|---|---|---|
| `rel=canonical` | ✅ | header.php (глобально) |
| `meta description` уникальная | ✅ | Компонент каталога / настройка страницы |
| `og:image` (1200×630) | ✅ | Шаблон раздела / детальной страницы |
| `loading="lazy"` для фото | ✅ | Компонент каталога |
| `width/height` на img | ✅ | Компонент каталога |
| JSON-LD (Service/Product/FAQ/LocalBusiness) | ✅ | result_modifier.php / template.php |
| BreadcrumbList JSON-LD | ✅ | Компонент навигации |
| Хлебные крошки (визуальные) | ✅ | Компонент навигации |
| Калькулятор цены (AJAX) | 🟠 Желательно | Отдельный компонент / виджет |
| FAQ аккордеон | 🟠 Желательно | Шаблон детальной / раздела |

## 📊 KPI для новых лендингов

| Метрика | Целевое значение (3 мес) | Как измерять |
|---|---|---|
| **Индексация** | 100% новых страниц в SEARCHABLE | Вебмастер → Страницы в поиске |
| **Позиции основных запросов** | ТОП-5 для 80% целевых запросов | Вебмастер → Мониторинг запросов |
| **Органический трафик** | +30% к базовому на кластере | Яндекс.Метрика / GA4 |
| **Заявки/Лидсы** | +50% к базовому | CRM / Метрика цели |
| **CTR сниппета** | >5% (бренд), >3% (коммерческие) | Вебмастер → Статистика страниц |
| **Время на странице** | >2 мин (статьи), >1 мин (лендинги) | Метрика |
| **Глубина просмотра** | >2 страницы/сессию | Метрика |
